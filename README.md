# C string.h Implementation

A learning exercise implementing common functions from the C standard library’s `string.h` (plus a few related `stdio` string I/O helpers) using pointer arithmetic instead of indexing or library calls.

## Functions Implemented

All functions are prefixed with `my_` and declared in `my_string_functions.h`.

### String manipulation
- `my_strcpy` / `my_strncpy` — copy
- `my_strcat` / `my_strncat` — concatenate
- `my_strcmp` / `my_strncmp` — compare
- `my_strlen` — length

### Character / stream I/O
- `my_fgets` / `my_fputs` / `my_fgetc` / `my_fputc`
- `my_gets` / `my_puts`
- `my_getchar` / `my_putchar`
